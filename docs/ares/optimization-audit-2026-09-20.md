# AresPrism 本地优化与验证记录

日期为 2026-09-20，基线为 `eab0cb0`（0.10.4）。本次保持现有功能、布局和使用流程，优化已写入工作区，尚未提交或发布，也未替换 `/Applications/AresPrism.app`。

## 已完成

- 保存按文件串行执行，保存期间的新编辑保持未保存状态；返回主页、切换项目、关闭窗口及 macOS 菜单退出会等待保存。写入失败保留编辑内容，并显示可重试提示。
- 刷新按文件大小和修改时间识别变化，与最新编辑状态合并，避免迟到的磁盘读取覆盖输入。后台无变化刷新不读取正文、不增加内容版本；手动刷新仍可强制重读。
- 快捷键、预览、多文档和 AI 完成后的编译统一排队，最多 3 个并发任务；合并同根重复请求，保存失败不启动编译，项目切换后丢弃旧结果。保留编译前历史快照。
- PDF 缓存使用不可变字节数组身份，移除可能碰撞的抽样指纹；并发打开去重，活动查看器持有资源引用，闲置缓存维持 5 个文档上限。离屏页面释放画布及文本层，保留页面几何和被选中的文本。
- MuPDF 文档、页面、文本和像素资源显式释放；Worker 初始化超时、崩溃及重置会拒绝等待中的请求。SyncTeX 索引按编译版本缓存。
- 浮动窗口接收文件及聊天状态增量，持续输出采用限频发送。PDF 按内容版本加载。实测修复隐藏构建目录权限造成的浮动预览空白，改为后端读取已知编译产物。
- 编辑器与 PDF 视图缓存移出 UI 模块，工作区和设置按需加载。文件树不再因每个正文字符而重建，目录解析采用延后更新。
- 辅助字号跟随应用字号，滑块关联标签，工具栏响应项目尺寸变化，More 按钮恢复可见键盘焦点，并支持减少动态效果。

## 性能证据及边界

| 同机比较 | 基线 | 优化后 |
| --- | ---: | ---: |
| 首页静态 JavaScript 依赖总量 | 2,072,140 字节 | 764,514 字节 |
| 无变化刷新正文读取 | 重新读取 | 0 次（回归测试） |
| 8 个并发闲置 PDF 缓存请求的保留数 | 8 | 5 |
| 30 轮真实 MuPDF 操作的峰值 RSS 中位数 | 253 MiB | 246 MiB |
| 同一 MuPDF 小基准耗时中位数 | 338 ms | 364 ms |

首页依赖量减少约 63.1%。比较使用同一套已安装依赖，基线源码在临时目录单独构建；统计入口和 App 的静态导入闭包，不含按需打开的工作区、WASM、字体及 CSS。这是加载体积变化，不代表启动耗时减少相同比例。

MuPDF 基准使用同一份 12 页 PDF，执行 30 轮打开、页面尺寸读取、96 dpi 渲染、文本和链接提取、缩略图生成及关闭，两个版本各运行 3 次。峰值 RSS 包含 Node 和 WASM，并非整个桌面应用。显式资源释放存在小幅 CPU 成本，因此本次不声称 PDF 渲染速度提升。长时间实际写作的帧率、整机内存及 Windows/Linux 原生流程尚未量化验证。

生产构建仍有大于 500 kB 的按需模块提示；Rust 在 macOS 上仍有原有 Windows 专用函数未使用提示。它们不影响本次构建及测试结果。

## 浮动预览编译修复

针对随后反馈的浮动状态无法编译问题，原生复现确认浮动窗口缺少 ⌘/Ctrl+Enter 处理；测试项目的按钮编译可以执行，但请求没有携带浮动窗口选择的后端和默认引擎。此前的浮动验证只覆盖 PDF 显示，没有覆盖这些操作。

- 预览加入编译快捷键，跳过编辑器已处理的事件、输入法组合输入和长按重复事件，卸载时移除监听。
- 按钮及快捷键共用编译请求，携带项目、源文件、强制重编译标志、后端和默认引擎；主窗口保存源文件后编译，忽略其他项目或已删除文件的请求。
- 新增 8 项回归测试，前端共 274 项通过。TypeScript、Biome 和 macOS debug 应用构建通过。
- 原生测试中，将临时文档标题分别改为 `Floating Preview Shortcut Verified` 和 `Floating Preview Button Verified`，在浮动窗口使用 ⌘Enter 与按钮编译后，均直接看到新标题。移除测试文档的固定引擎声明后，在浮动窗口切换至 pdfLaTeX，后端日志确认实际执行 pdfLaTeX；结束时恢复原来的 XeLaTeX 设置。

修复保留 `% !TEX program` 优先于默认引擎的既有规则。本次仍为本地代码及测试包，没有替换 `/Applications/AresPrism.app`。
