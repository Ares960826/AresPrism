# AresPrism 变更

只记本产品相对上一版的差。上游 ClaudePrism 的历史仍在 git 里，不抄到这里。

## 0.12.1 — 2026-10-06

- 版本恢复更安全：恢复前弹出确认，并先把当前文件存为一个版本；恢复后可一键“Undo”。AI 正在运行或有待处理的 AI 改动时不允许恢复。
- 修复恢复后编辑器里的旧内容可能写回、覆盖已恢复文件的问题；恢复期间暂停保存、切换项目和发送 AI 消息。
- 修复恢复过一次后，更早的版本从列表中消失的问题；版本按真实先后顺序排列，查看改动时与真正的上一版比较。
- 版本名称支持空格和中文，重名或无效时给出提示。
- figures 等目录中的 PDF 插图纳入版本历史；恢复旧版本时不会删掉它们；保留用户自定义的排除规则。
- 版本历史与 Git 操作移到后台执行，大项目不再卡住界面。
- Git 面板只使用项目自身目录下的仓库，不再误操作上层仓库；提交会包含删除的文件，并使用本机 Git 用户信息。

## 0.12.0 — 2026-10-05

- Cmd+S（及 Ctrl+S）保存后立即编译当前论文；常规编译按钮移到编辑器工具栏，与并行编译并列，预览栏只显示编译进度。
- 编辑器中 Cmd+X 恢复为剪切；“框选截图提问”快捷键只在非文本区域生效。
- 选中代码后可“Add to chat”（⌘L），把所选内容作为整块引用插入 AI 输入框光标处，可整块删除，发送时展开为带文件与行号的代码块；不再把编辑器里残留的选区静默附加到提问中。
- PDF 预览支持像阅读器一样拖选、双击选词与复制，选区高亮可见，浮窗新增“Copy”。修复 MuPDF 新格式下文本层为空的问题。
- Tab 接受补全；新增 \ref 标签、\cite 文献键、\input 文件和 \includegraphics 图片路径补全。
- 编辑器可在“自动换行”与“不换行 + 列标线”之间切换，列号可在设置中调整。
- Claude Code 模型列表补全：新增 Fable、1M 上下文等别名，并读取已安装 CLI、Claude Code 设置及 API 实际可用模型，可填写任意模型 ID；所选模型重启后保留。
- 聊天框收起改为顶部隐藏长条：顶边拖动调整高度，其下悬停出现长条，点击即收起。
- 精简注入给 AI Agent 的上下文：移除强制规划、限制编辑方式的系统提示与乱码，其他 CLI 仅在新会话开头附带简短说明；新项目的 CLAUDE.md 改为简短准确的版本；仅在用户选择时传递推理强度。
- 按钮点击更跟手：非前台窗口首次点击即生效，标题栏拖动区不再遮挡工具栏按钮，去除悬停放大动画并增加按下反馈。

## 0.11.0 — 2026-09-28

- 首页增加在 Finder 中显示项目和将整个项目移至系统废纸篓的操作；移除列表与移除目录分开，删除前明确显示完整路径并确认。
- 文件树支持主动创建多目录工作区、添加与移除项目目录；首页可重新打开保存的工作区，默认仍为单目录模式。切换目录先保存并恢复各自的编辑标签。
- 软件缩放支持 Cmd/Ctrl +/−、0 重置、固定百分比与 10% 步进，重启保留设置；PDF 触控板缩放也量化为 10% 档位。
- 增加 OpenCode Go API key 预设及会话标识；按模型区分 Chat Completions、Responses 和 Anthropic 接口。
- SyncTeX 严格绑定指定主文件；源文件定位切换至所属 PDF，优先使用原生 SyncTeX 行列查询，避免退回另一份最近构建。修复预览初始化与重渲染误暂停光标跟随的问题，PDF 页未就绪时等待后再定位。修正嵌套页面容器导致后续页坐标被误算为第一页的问题，并计入软件缩放比例。

## 0.10.6 — 2026-09-27

- Ctrl+S 保存并编译当前论文，编辑器及浮动预览统一支持；macOS Cmd+S 继续保存，原有编译快捷键保留。
- 文件树使用带颜色与格式字样的图标，区分 TeX、Bib、PDF、Python、JSON 等文件。
- Codex 优先选择较新的已安装运行时，从其 app-server 查询 OAuth 实际可用模型，移除硬编码与配置中未经验证的模型列表。
- 修正本地 CLI 被误识别为直接 API 接入的问题；普通 stderr 与可恢复工具诊断不再直接成为顶层红色错误，真实请求失败保留并显示清晰信息。

## 0.10.5 — 2026-09-26

- 修复从父目录打开嵌套论文时找不到章节的问题；不同目录下同名主文件使用独立编译缓存，保持多文件并行编译。
- 并行编译结果、错误提示和 PDF 标签按主文件隔离；后台任务完成不再切换当前预览，章节根文件与 SyncTeX 路径正确对应所属论文。
- 保存按文件串行执行，退出、返回主页和切换项目等待保存；刷新保留期间的新编辑，避免磁盘读取覆盖输入。
- 浮动预览支持编译快捷键和按钮，并传递所选编译器及默认引擎；编译入口统一排队、保存并合并重复请求。
- 改进 PDF 缓存与 MuPDF 资源释放、浮动窗口状态同步及工作区按需加载。
- 修正发布脚本中的产品名、仓库和自动更新下载地址。

## 0.1.0 — 2026-09-17

- 独立应用身份：**AresPrism**，bundle id `dev.ares.prism`，青绿图标
- 可与官方 `/Applications/ClaudePrism.app` 并排安装
- 编译后端增加 **latexmk**；TeX Live / latexmk 可选 pdfLaTeX、LuaLaTeX、XeLaTeX

- 关闭指向官方 ClaudePrism 的自动更新
- 默认工程目录 `~/Documents/AresPrism`
